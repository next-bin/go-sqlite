# ccir
Package ccir translates [cc](https://github.com/next-bin/go-sqlite3/pkg/cc) ASTs to internal representation. (Work In Progress)

Installation

    $ go get github.com/next-bin/go-sqlite3/pkg/ccir

Documentation: [pkg.go.dev/github.com/next-bin/go-sqlite3/pkg/ccir](https://pkg.go.dev/github.com/next-bin/go-sqlite3/pkg/ccir)

Based on [modernc.org/sqlite](https://gitlab.com/cznic/sqlite) by CZ.NIC z.s.p.o.
