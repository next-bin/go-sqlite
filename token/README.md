# token

Package token is a variant of the stdlib package token with types FileSet and Token removed

Installation

    $ go get [-u] github.com/next-bin/go-sqlite/v2/token

Documentation: [pkg.go.dev/github.com/next-bin/go-sqlite/v2/token](https://pkg.go.dev/github.com/next-bin/go-sqlite/v2/token)
