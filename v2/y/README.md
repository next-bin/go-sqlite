y
=

Package y converts yacc source code to data structures suitable for a parser generator.

Installation

    $ go get github.com/next-bin/go-sqlite/v2/y

Documentation: [pkg.go.dev/github.com/next-bin/go-sqlite/v2/y](https://pkg.go.dev/github.com/next-bin/go-sqlite/v2/y)

Based on [modernc.org/sqlite](https://gitlab.com/cznic/sqlite) by CZ.NIC z.s.p.o.
