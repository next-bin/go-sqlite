# internal
Things that cannot be imported by 3rd party packages.

Packages in this repository

* Package [buffer](https://pkg.go.dev/github.com/next-bin/go-sqlite/v2/internal/buffer) implements a pool of pointers to byte slices.
* Package [file](https://pkg.go.dev/github.com/next-bin/go-sqlite/v2/internal/file) provides an os.File-like interface of a memory mapped file.
* Package [slice](https://pkg.go.dev/github.com/next-bin/go-sqlite/v2/internal/slice) implements pools of pointers to slices.

Based on [modernc.org/sqlite](https://gitlab.com/cznic/sqlite) by CZ.NIC z.s.p.o.
