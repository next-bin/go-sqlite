# gc

Package GC is a Go compiler front end. (Work in progress, API unstable)

Installation

    $ go get github.com/next-bin/go-sqlite/v2/gc

Documentation: [pkg.go.dev/github.com/next-bin/go-sqlite/v2/gc](https://pkg.go.dev/github.com/next-bin/go-sqlite/v2/gc)

Based on [modernc.org/sqlite](https://gitlab.com/cznic/sqlite) by CZ.NIC z.s.p.o.
